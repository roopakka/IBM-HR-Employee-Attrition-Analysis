# IBM HR Employee Attrition Analysis

## Overview
Analyzed the IBM HR Employee Attrition dataset using Excel and SQL to identify factors influencing employee turnover.

## Tools Used
- Excel
- Power Query
- SQL
- MySQL

## Key Findings
- Overall Attrition Rate: 16.12%
- Higher attrition among overtime employees.
- Sales and R&D departments showed higher turnover.
- Lower salary bands experienced greater attrition.

## Project Components
- Data Cleaning using Power Query
- Excel Dashboard
- SQL Analysis
